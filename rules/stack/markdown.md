# Markdown

- Write each paragraph on one line; do not hard-wrap prose.
- Keep the required line breaks in code blocks, tables, lists and frontmatter.
- Use one first-level heading per file and do not skip heading levels.
- Put file names, commands and identifiers in inline code, such as `phpunit.xml` or `git log`.
- Write values to fill in as `<placeholder>`, such as `<database_name>`, inside inline code or a code block.
- Fence code blocks with a full language name when known, such as `markdown`, `bash` or `yaml`, not an abbreviation such as `md` or `sh`.
- Format each code block by the project's `.editorconfig` for its language.
