# Security policy

This repository is maintained on a best-effort basis, without releases or support commitments. Only the current state of the default branch is considered.

## Reporting a vulnerability

Do not report vulnerabilities through public issues, pull requests or discussions. Report them privately through [GitHub private vulnerability reporting](https://github.com/jarovarga/ccc/security/advisories/new) instead, with a description of the issue, the affected commit and the steps to reproduce it.
